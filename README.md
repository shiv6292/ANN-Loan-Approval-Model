An Artificial Neural Network (ANN) built with TensorFlow/Keras that predicts whether a loan application will be **Approved** or **Rejected**, and gives an approval probability for any applicant entered by the user.

> **Educational prototype only.** The data is fully synthetic. This is not a real credit-decision system and must not be used for real lending decisions.

---

## Features

- Generates a **synthetic dataset of 5,000 loan applicants** (no real or personal data).
- Trains a multilayer ANN with **Dropout** and **early stopping**.
- Reports accuracy, precision, recall, F1-score, ROC-AUC and a confusion matrix.
- Saves training curves, confusion matrix and ROC curve as PNG images.
- **Interactive prediction:** enter applicant details and get *Loan Approved / Loan Rejected* with the probability.

---

## Dataset (synthetic)

Generated by the script itself and saved as `synthetic_loan_data.csv`.

| Feature | Unit | Range |
|---|---|---|
| age | years | 21 - 65 |
| income | Rs / year | 15,000 - 250,000 |
| credit_score | score | 300 - 850 |
| loan_amount | Rs | 10,000 - 600,000 |
| loan_term_months | months | 12 - 120 |
| employment_years | years | 0 - 40 |
| existing_debt | Rs | 0 - 150,000 |
| owns_property | 0 / 1 | No / Yes |
| **approved** (target) | 0 / 1 | Rejected / Approved |

Approval depends on a hidden rule (credit score, income, debt-to-income ratio, experience, property) plus random noise, so the ANN has a real pattern to learn. Overall approval rate is about 40%.

---

## Model Architecture

```
Input (8) -> Dense 16 (ReLU) -> Dropout 0.2 -> Dense 8 (ReLU) -> Dense 1 (Sigmoid)
```

- **Trainable parameters:** 289
- **Loss:** binary cross-entropy
- **Optimizer:** Adam (learning rate 0.001)
- **Training:** batch size 32, up to 100 epochs, 20% validation split, early stopping (patience 10)
- **Preprocessing:** 80/20 stratified train-test split, `StandardScaler` fitted on training data only
- **Decision rule:** probability of 0.5 or more means Approved, otherwise Rejected

---

## Results (test set of 1,000 applicants)

| Metric | Value |
|---|---|
| Accuracy | 80.8% |
| Precision | 75.2% |
| Recall | 78.2% |
| F1-score | 76.7% |
| ROC-AUC | 0.885 |

Confusion matrix: TN = 492, FP = 104, FN = 88, TP = 316.

Accuracy is not 100% because the data contains deliberate random noise. Exact numbers can differ by about 1% between runs.

## How to Run

### Option 1: Google Colab (recommended for the demo)

1. Go to [colab.research.google.com](https://colab.research.google.com).
2. **File -> Upload notebook** and select `Loan_Approval_ANN_Colab.ipynb`.
3. Click **Runtime -> Run all** (about one minute).
4. Use the form in **Step 9B** to enter an applicant and click **Predict**.
5. The last cell downloads `loan_outputs.zip` with the graphs, dataset and model.

### Option 2: VS Code / terminal

```bash
pip install numpy pandas scikit-learn matplotlib tensorflow
python loan_approval_ann.py
```

After training, the terminal asks for the applicant details one by one and prints the decision. Outputs are saved in the `loan_outputs/` folder.
